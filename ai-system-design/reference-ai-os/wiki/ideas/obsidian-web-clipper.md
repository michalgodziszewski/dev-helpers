# Idea: Obsidian Web Clipper → `wiki/raw/`

**Status:** not started
**Priority:** 4

## What

Install the Obsidian Web Clipper browser extension, point its default save location at
`wiki/raw/` instead of the default "clippings" folder.

## Why

Makes adding new sources to the wiki (articles, docs, other transcripts) a one-click action
instead of manual copy-paste — lowers the friction that determines whether the wiki actually
stays alive.

## How

See [obsidian-raw-wiki-ingestion](../notes/techniques/obsidian-raw-wiki-ingestion.md#setup) step
5. Obsidian is already installed and pointed at `wiki/` as a vault.
